空闲—

擦除前请先在 9008 下完整回读备份全字库（eMMC 全镜像），擦除后数据不可恢复。本工具按“原样”提供，刷机风险自负。

现在需要你手动完成

第 1–5 步
  1. 恢复出厂设置

    设备会重启几次并进入恢复模式，在里面选择“恢复出厂设置”。

  2. 连接无网络热点

    手机关掉 Wi-Fi 和移动数据，再开热点；平板连接该热点完成激活。

  3. 打开开发者选项

    设置 → 关于平板电脑，连续点击“HarmonyOS 版本号”，直到提示已开启开发者模式。

  4. 开启 USB 调试

    系统和更新 → 开发人员选项：打开“USB 调试”，关闭“监控 ADB 安装应用”，打开“仅充电模式下允许 ADB 调试”。

  5. 连接电脑并授权

    用数据线连接电脑，在平板上允许 USB 调试，之后会自动停用相关应用。

第 7 步冻结完成后，请不要打开应用市场、云空间、华为账号、系统更新等华为账号相关功能。
